# 从原版 CatWrt 迁移

## 适用对象

本文适用于从原版 CatWrt（项目 `miaoermua/CatWrt`，基于 LEDE）迁移到 CatWrt Next（基于 ImmortalWrt 25.12.2）的用户。

## 前置条件

原版需为最后一个版本 v25.8。更老的版本请先升级到 v25.8，或者直接全新刷写 CatWrt Next。

## 迁移前备份

在 LuCI 的“系统 → 备份/恢复”中导出配置，并将备份保存到设备之外。另行记录以下设置，供迁移后核对：

- WAN 类型（DHCP／PPPoE）。
- LAN 地址。
- 端口转发。
- 静态路由。
- 定时任务。

## 迁移步骤

1. 从本项目 Releases 下载与设备启动方式（EFI／BIOS）对应的 squashfs 镜像。使用供刷写的 `img.gz`，不要使用虚拟机磁盘格式 `qcow2`；刷写前核对发布页提供的 SHA256 校验和。
2. 将镜像传到原版设备，在原版系统上执行 `sysupgrade -v <镜像>`，将 `<镜像>` 替换为实际镜像文件名，保留配置升级。
3. 等待设备完成刷写并重启，期间不要断电。重启后按下面的清单逐项检查。

## 迁移后检查清单

- [ ] LAN 地址与主机名是否保持原来的设置。
- [ ] WAN 是否正常拨号或获取到地址。
- [ ] DHCP 客户端能否获取租约。
- [ ] DNS 解析是否正常。
- [ ] 防火墙端口转发是否生效。
- [ ] 静态路由与定时任务是否保留并正常运行。
- [ ] LuCI 语言是否符合预期。
- [ ] 检查 root 密码，如果仍是原版的 `password`，立即修改。

## 不兼容项

- 软件包管理器从 opkg（ipk）更换为 apk（apk-tools v3）。原版软件源全部失效，已安装的插件（包括手动安装的插件）不会带过来，需重新安装兼容的软件包。
- 本固件不提供原版特有插件，例如 easytier、雷神加速器、校园网套件等。
- 本项目不提供自动迁移工具。
- 不支持从 v24.9 及更早版本保留配置迁移。

## 回滚

需要回滚时，重新刷回原版 CatWrt 的 v25.8 镜像，刷写前核对镜像的 SHA256 校验和。回滚会丢失迁移期间的配置，请先备份，并保留迁移前导出的原版配置备份。

## 风险提示

跨底座保留配置属于实验性支持，迁移后请按检查清单逐项确认。优先使用 squashfs 变体。
